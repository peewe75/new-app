## Contesto e convenzioni comuni

PROJECT CONTEXT
You are building part of "Seguito", a TypeScript (Node 22, ESM) app in /home/user/new-app for an Italian law firm (Avv. Vincenzo Sapone, Cantù; criminal law, crisis/insolvency, civil). Purpose: after a phone call or meeting is recorded with a Plaud Note Pro and transcribed by Plaud, Seguito takes the transcript, has Claude extract appointments, engagements (incarichi), fee agreements (accordi economici), deadlines (scadenze), documents to receive/send, emails to send and tasks; it shows the lawyer a report with checkboxes ("human in the loop"); on approval it executes: calendar file (.ics), email draft (.eml, opens as draft), notes/matters in the case-management system ("gestionale", a JSON file for now), and sends the transcript to the studio mailbox (as .eml draft). Nothing is executed without approval.

## Modulo 1 – Fonti (Plaud API e file)

YOUR MODULE: recording sources (Plaud API and local files).

PLAUD DEVELOPER API (reverse-read from the official @plaud-ai/cli 0.3.14; use exactly this):
- Base URL from config (default "https://platform.plaud.ai/developer/api"). Every request: headers Authorization "Bearer <access_token>", Accept "application/json", plus "x-pld-region: <region>" when config.plaud.region is set. Use AbortSignal.timeout(30000).
- List: GET {base}/open/third-party/files/?page={page}&page_size={size} -> JSON { data: PlaudFile[], page: number }.
- Detail: GET {base}/open/third-party/files/{encodeURIComponent(id)} -> PlaudFile with:
  id (string), name (string), created_at (string), start_at (string|null), duration (ms, number|null), serial_number?, presigned_url?,
  source_list?: Array<{ data_type: "transaction" | "transaction_polish" | "outline" | "mark_memo" | string, data_content?: string, data_link?: string }>,
  note_list?: Array<{ data_type: "auto_sum_note" | string, data_title?: string, data_tab_name?: string, data_content?: string, data_link?: string }>.
- Block content: use data_content when it is a non-empty string, otherwise fetch data_link as text with safety checks: https only, no userinfo in URL, no IP-literal host, timeout 30 s, max 20 MB (abort if larger); error otherwise.
- Transcript: the "transaction" block (fallback: "transaction_polish") content is a JSON string: Array<{ start_time: number (ms), end_time?: number (ms), speaker?: string, content?: string }>. Map to Segment { index, startMs, endMs (null if missing), speaker (default "Parlante"), text: content trimmed }; drop segments with empty text; index = position after filtering (0-based, contiguous). If there is no transcript block or it is empty -> throw PlaudNotReadyError (Italian message: the transcript is not yet available in Plaud).
- Summary: from note_list notes with data_type "auto_sum_note", prefer one whose data_title or data_tab_name contains "Seguito" (case-insensitive; the studio's custom template), else the first; plaudSummary = its content or null.
- Timestamps: the API may return timestamps without a timezone; those are UTC (append "Z" when the string has a time and no "Z"/offset). startedAt = start_at ?? created_at, as ISO string (new Date(...).toISOString()). Throw a clear error if unparsable.
- Auth tokens: after the user runs "npx @plaud-ai/cli login", tokens are stored in config.plaud.tokensPath (default ~/.plaud/tokens.json) as JSON { access_token, refresh_token?, token_type?, expires_at?: number (epoch ms) }. If the file is missing/invalid -> PlaudAuthError with Italian message telling to run "npx @plaud-ai/cli login". If expires_at is within 60 s: POST config.plaud.refreshUrl with Content-Type application/x-www-form-urlencoded, body refresh_token=<token>, Accept application/json; response { access_token, refresh_token?, token_type?, expires_in?: seconds }; save back to the same file in the same format (keep the old refresh_token if none is returned; expires_at = now + expires_in*1000), file mode 0600, directory mode 0700, atomic write (temp file + rename). Refresh rejected (401/403) or HTTP 401/403 on API calls -> PlaudAuthError. Other non-2xx -> PlaudApiError with status (no response bodies in messages, they may contain personal data).
- Never log tokens or transcript content.

Rossi," / "Egregio Avvocato,"), clear and brief, no signature (added by the system), no legal advice beyond what was said, no admissions or sensitive details towards counterparts, never mention fees to anyone but the client; recipientEmail only if spoken in the call, otherwise null (the system fills it from the case-management system).
  * Evidence: for every participant, action and doubt give 1-3 evidence items: "segment" = the #index shown in the transcript, "quote" = a short literal excerpt (max ~15 words) copied exactly from that segment.
  * Confidence calibration: 0.9+ explicit and confirmed; 0.6-0.85 implied; below 0.5 do not propose.
  * summary: max 5 lines, factual, Italian.
  * The Plaud summary (if provided) is a secondary aid that can contain errors: the transcript prevails.
